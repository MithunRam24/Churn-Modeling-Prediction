# Churn-Modeling-Prediction
Churn Modeling Prediction is a binary classification model that gives the probability of a customer is likely to leave or not.

### Steps:
   1. Visualize data distributions and find correlations between customer attributes and churn's recent activity. 
   2. Convert categorical variables (like gender or subscription plan) into numerical values using One-Hot Encoding or Label Encoding.
   3. Identify missing values and decide on an imputation strategy.

### Software Used:
   -Pandas
   -NumPy
   -ScikitLearn
   -StreamLit
   -TensorFlow
   -TensorBoard
